# 8. 챗 답변 형식과 출처 표기

**목표:** ChatGPT처럼 읽기 쉬운 답변(제목·목록·굵게), 문단 끝 출처 칩, 후속 질문 추천. 출처는 논문 제목 중심의 보편적 표기.

## 내가 입력한 프롬프트

① 답변 형식 (참고 링크를 함께 붙임)
```
ai챗봇 ui를 다음 링크의 형식으로 만들어줘. 출처표기방식, 출력된 텍스트 형식 등을 참고해줘.
```

② 자료 밖 질문·출처 표기 방식 (6-2의 "수정 사항 적용해줘" 1·2번)
```
1. 자료에 없는 질문은 … api 활용하여 ai생성 답변으로 보충 설명해줘. 이 때는 출처표기 명시해.
2. … 별칭으로 출처가 표기되는데 논문명, 페이지 쪽수 등 보편적인 출처표기 방식으로 별칭을 대체하도록 수정해줘.
```

③ 출처 제목 바로잡기
```
api 질문챗봇을 테스트해보니 출처에 인용문서에 제목 대신 다른 텍스트가 뜨는 것 같아.
인용 문서의 제목은 첫 장의 제목 텍스트로 출처 표시가 나오도록 해줘.
제목이 json파일에 들어있지 않다면 추가하는 작업도 출처표시를 위해 필요하다면 실행해.
```

## 결과 요약
- 답변을 마크다운으로 렌더링, 문단 끝 출처 칩(누르면 상세), 답변 아래 "출처 n" 버튼으로 전체 목록
- 출처: 첫 줄은 논문 첫 장 제목, 아랫줄에 저자·연도·발행처·쪽수. 본문에서 실제 인용한 문서만 표시
- 자료 밖 내용은 AI 일반 지식으로 보충하고 `[AI]` 출처로 구분
- 마지막 답변 아래 후속 질문 버튼 3개
- 숫자 가드레일 보완: 출처의 논문 제목·절 제목에 있는 숫자(예: "500MW")는 허용

- 자료에 없는 질문에 `[AI]` 표기가 붙는가?
- 답변 속 숫자가 "(계산 결과 카드 참조)"로 잘못 바뀌지 않는가?
