# Mock 기술 문서 (가상)

실제 문서가 제공되기 전까지 RAG 검색에 쓰는 **가상 문서**입니다. 수치·사례·발전소명은 모두 지어낸 것입니다.
`data/docs_masked/`에 인제스트 결과가 생기면 이 폴더 대신 그쪽을 검색합니다(README "실제 문서 넣기" 참조).

형식: 맨 위 front matter(`alias`, `title`, `lang`) + `## 섹션` 단위. 이 README는 색인에서 제외됩니다.
출처 표기용 `authors`(세미콜론 구분)·`year`·`publisher`·`url`·`pages`와 절별 쪽수(`## 절 제목 (p. 12)`)도 쓸 수 있지만,
가상 문서라 저자·쪽수는 넣지 않았습니다(화면에는 제목·절과 "예시 문서" 배지가 표시됨).
