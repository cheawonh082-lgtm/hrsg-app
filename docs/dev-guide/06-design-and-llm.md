# 6. 디자인 개편 + 실제 LLM 연결

## 6-1. 레퍼런스 이미지로 디자인 바꾸기

**목표:** 대시보드 레퍼런스 이미지와 같은 배치(왼쪽 남색 사이드바 + 오른쪽 본문)·카드 스타일로 바꾼다.

### 내가 입력한 프롬프트 (이미지를 채팅에 첨부)
```
다음 UI 이미지의 레퍼런스를 참고해서 웹사이트의 디자인 및 배치구조를 수정해줘
```
계산기 세부 조정 (이미지 첨부, 여러 번에 나눠 요청):
```
운전 지표를 2-1에 배치해줘.
운전지표 바로 다음에 HRSG도식화 위 이미지 참고해서 추가해.
2-1에 세정 시 효과를 세정 시 회수효과로 이름변경하고 위 이미지 중 열회수 효율 추이 그래프 이미지로 시각화해서 추가해줘.
2-3에 예상 성능 지표는 위 이미지 중 핵심성능지표를 참고하여 kpi 시각화 추가해줘.
```
```
HRSG구조도 지워줘. HRSG도식에 마우스 가져다대면 위험지표 볼 수 있도록 수정해줘.
홈에 있는 세정 공법별 비용 비교에서 마우스 가져다대면 지표가 뜨는데 화면 떄문에 잘려서 안 보여. 잘리지 않는 위치로 조정되는 기능 추가.
2-3에 예상성능지표 이름을 핵심성능지표로 변경.
위 수정이 끝나고 계산기 소분류 항목에 2-1 2-2 2-3 숫자 라벨링 없애줘. 문자만 보이도록 수정.
```

### 결과 요약
- PC: 왼쪽 고정 사이드바(하위 메뉴 펼치기) + 상단 바, 모바일: 상단 바 + 하단 탭바 + 전체 메뉴 드로어
- 홈 화면(요약 KPI, 세정 공법 비용 도넛), 계산기 3개 탭(운전 지표·HRSG 도식·회수효과 / 손실 비교 / 핵심 성능 지표)
- 수정 파일: `frontend/src/components/layout/*`(AppShell, SidebarNav, navItems), `pages/HomePage.tsx`, `components/calculator/*`, `index.css`(색 토큰)

## 6-2. 실제 LLM 연결 (Gemini → Claude)

**목표:** Fake LLM 대신 실제 LLM으로 답한다. 공급자는 환경변수만 바꿔 고를 수 있게 한다.

### 내가 입력한 프롬프트
```
AI질문 항목에 사용할 API Key 생성 및 연동해줘. 추가적으로 필요한 사항 있으면 요구해
```
```
모델은 구글 ai스튜디오 api로 변경.
```
(최종) Claude로 교체 — 다른 요청과 함께:
```
수정 사항 적용해줘.
1. 자료에 없는 질문은 "확인되지 않습니다"로 끝낼지, 일반 지식으로 보충 설명할지 정해 주세요.
   --> api 활용하여 ai생성 답변으로 보충 설명해줘. 이 때는 출처표기 명시해.
2. 내부 문서 기반으로 답변 생성 시 현재는 별칭으로 출처가 표기되는데 논문명, 페이지 쪽수 등
   보편적인 출처표기 방식으로 별칭을 대체하도록 수정해줘.
3. api 모델을 클로드로 바꿔줘. 클로드 api키가 있으니 모델 바꿀 때 요청해줘.
```
Claude가 키를 넣을 위치를 알려 주면 **직접** 입력하고:
```
키 두 곳 모두에 넣었어. 계속 진행해줘
```

> ⚠ API 키를 채팅에 붙여 넣지 않는다. 대화 기록 파일(`~/.claude/projects/...`)에 그대로 남는다.
> "키는 어디에 넣으면 돼?"라고 묻고, 알려 준 파일·대시보드에 직접 넣은 뒤 "넣었어"라고만 답한다.

### 결과 요약
- `LLM_PROVIDER=fake|gemini|claude`, `LLM_MODEL`, `LLM_API_KEY` (루트 `.env`, Git 제외)
- 두 공급자가 같은 프롬프트·출력 스키마(`llm/prompts.py`)를 쓴다 → 키만 바꾸면 전환
- 현재: `claude` / `claude-sonnet-5-5` (사용량만큼 과금)
- Claude 구조화 출력은 선택(nullable) 파라미터가 16개까지라 입력값을 `{field, value}` 목록으로 받도록 바꿈
- 테스트는 `.env`와 관계없이 항상 Fake (`tests/backend/conftest.py`)

### 파일 위치
```
hrsg-reference-app\
├─ .env                         LLM_PROVIDER / LLM_MODEL / LLM_API_KEY  (직접 입력, Git 제외)
└─ backend\app\chat\llm\        base.py, fake.py, gemini.py, claude.py, prompts.py
```
배포판 키는 Render 대시보드 → `hrsg-reference-api` → Environment → `LLM_API_KEY` (9단계).
