# 12. 챗 대화 기록 사이드바 + 체크리스트 상태 토글

## 12-1. 대화 기록

**목표:** 이전 대화를 저장해 두고 다시 연다. PC는 왼쪽 사이드바(접기 가능), 모바일·태블릿은 드로어 (PRD §3.2 "대화 목록").

### 내가 입력한 프롬프트
```
배포용에 ai챗 이전 기록 저장을 사이드바에 띄우는 형식으로 처리해줘
```
```
대화기록을 접었을 때 우측 상단에 있는 펼치기 바를 좌측 상단으로 이동시켜줘.
```

### 결과 요약
- 대화를 **브라우저 localStorage**(`hrsg-chat`)에 최대 50개 저장. 서버는 대화를 기억하지 않고 Render 무료 디스크는 유지되지 않기 때문
  → 다른 기기·브라우저에서는 보이지 않음(사이드바에 안내)
- 새 대화 / 이전 대화 열기 / 삭제 / 전체 삭제. 새로고침하면 빈 새 대화로 시작
- 답변을 기다리는 중에 다른 대화로 옮겨도 답변은 원래 대화에 들어감. 새로고침으로 끊긴 대기는 "연결 끊김" 오류로 복원
- 사이드바를 접으면 제목 왼쪽(좌측 상단)에 펼치기 버튼

### 파일
```
frontend\src\store\chat.ts                  대화 목록 저장 (zustand persist)
frontend\src\components\chat\ChatHistory.tsx 목록 UI (사이드바·드로어 공용)
frontend\src\pages\ChatPage.tsx             사이드바·드로어 배치, 펼치기 버튼
frontend\src\store\chat.test.ts             저장소 단위 테스트
frontend\e2e\chat.spec.ts                   "대화 기록" E2E 2개
```

## 12-2. 체크리스트 상태 토글

### 내가 입력한 프롬프트
```
체크리스트에 대기,요청함, 수령 표시를 다른 버튼과 중복되지 않는 항목들만 체크표시로 고를 수 있도록 디자인 수정해줘.
```

### 결과 요약
- 동그라미 체크가 이미 '수령'(해제 = '대기')을 맡으므로 드롭다운을 없애고 **요청함·해당 없음** 토글(✓)만 남김
- 둘 중 하나만 켜짐. 켜진 토글을 다시 누르면 '대기'. 모바일에서는 토글이 한 줄을 차지(가로 넘침 방지)
- 파일: `frontend/src/components/checklist/ChecklistItem.tsx`, `frontend/e2e/checklist.spec.ts`

## 마무리 프롬프트
```
커밋하고 GitHub에 푸시해서 Render에 배포
```

## 확인할 것
- PC에서 대화 2개를 만든 뒤 새로고침 → 사이드바에서 이전 대화가 열리는가?
- 모바일 폭에서 "대화 기록" 버튼 → 드로어가 열리는가?
- E2E는 **Fake LLM 백엔드로** 돌린다: `LLM_PROVIDER=fake RAG_RETRIEVER=keyword npx playwright test`
  (실제 키 백엔드가 8000번에 켜져 있으면 Playwright가 그 서버를 재사용해 과금된다)
- 코드 정렬 도구(prettier)는 프로젝트에 설정 파일이 없으므로 기본값으로 돌리지 않는다(따옴표·세미콜론 스타일이 바뀜)
